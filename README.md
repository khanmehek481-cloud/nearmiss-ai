# NearMiss AI – Campus Safety Intelligence

NearMiss AI is a preventive campus safety prototype that collects near-miss incidents, analyzes their frequency and severity, and highlights locations that may require preventive action.

## Problem
Many safety systems focus on accidents after they happen. NearMiss focuses on the smaller incidents that almost caused an accident.

## Features
- Near-miss reporting
- Incident type and severity classification
- Location-based risk scoring
- Campus risk heatmap prototype
- Risk priority dashboard
- Recent incident feed
- Browser local storage
- Mobile-friendly interface

## Technology
- HTML
- CSS
- JavaScript
- Local Storage

## How to run
Open `index.html` in any modern web browser.

## Innovation
> Don't wait for an accident. Learn from the ones that almost happened.

## Future scope
A competition version can add a real ML model, cloud database, authentication, real campus maps, image-based hazard detection, and predictive analytics.
